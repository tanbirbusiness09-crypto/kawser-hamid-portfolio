# Kawser Hamid — Cinematic 3D Executive Hero (V4)

A minimal, animated, dark navy & gold one-page hero matching the approved concept. React 19 + Vite + TypeScript + Tailwind CSS v4, shadcn-compatible structure, Framer Motion, Lucide icons.

## Local

```bash
npm install
npm run dev
npm run build
```

## Notes
- Three portraits have transparent-background WebP assets produced from the user's supplied CEO images, at `public/assets/photos/kawser-hero-*`.
- Motion reacts to the mouse; animation pauses for reduced-motion preference and hover; navigation, dots, and touch swipes are functional.
- Consultation CTAs currently open an email inquiry. No booking/payment system is live.
- Company name and designation appear as supplied; all additional statistical achievement claims have been removed.
- Protected production domains are managed in Vercel; assets work relative to `/assets/`.
